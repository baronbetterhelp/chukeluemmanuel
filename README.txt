Theme:
Premium black, ivory and gold personal-brand website inspired by luxury entrepreneur websites, while remaining an original design.

DEPLOYMENT
1. Upload the CONTENTS of this folder to the root of the existing GitHub repository.
2. Keep wrangler.jsonc in the root.
3. Cloudflare deploy command: npx wrangler deploy
4. GitHub pushes should trigger Cloudflare automatically once Git integration is active.

IMPORTANT
Do not upload the ZIP itself to the website root. Extract it first and upload the files/folders inside.
