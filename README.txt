DEPLOYMENT
1. Upload the full contents of this folder to your hosting provider.
2. Connect the domain: chukeluemmanuel.com
3. Make sure HTTPS is enabled.
4. Create contact@chukeluemmanuel.com with your email provider, or configure forwarding to your preferred inbox.
5. Add https://chukeluemmanuel.com to Google Search Console.
6. Submit this sitemap in Search Console:
   https://chukeluemmanuel.com/sitemap.xml
7. Use URL Inspection in Search Console to request indexing of the homepage after launch.
